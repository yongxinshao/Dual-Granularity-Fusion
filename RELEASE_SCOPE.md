# Public release scope

This repository contains the reproducible public components of the project and the
underlying MMDetection3D framework. The project-specific DGFE/FEA implementation,
its private experiment configurations, pretrained checkpoints, datasets, logs, and
generated results are intentionally withheld until the paper is accepted.

The withheld files are not required to install the public framework. They will be
released in a follow-up version together with the final experiment configuration.

No dataset, annotation, checkpoint, or experiment output is included in this
repository. Please follow the official MMDetection3D data-preparation instructions
for public benchmarks.
